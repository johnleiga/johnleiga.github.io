Industrial Furnace Controls and Startup Automation

  1. Home

Zero waste startup, live bulk density control, and furnace stability improvements for a 14-furnace perlite expansion system.

This project improved startup repeatability, bulk density control, and process stability for a live 14-furnace perlite expansion system. The work combined mechanical troubleshooting, controls logic, PID tuning, DOE, operator workflow updates, and production validation.

The project supported $200K+ in expected annual savings and $500K+ in CapEx execution, with improvements centered on startup automation, live density feedback, and furnace stability.

System and problem

Perlite ore is expanded in a vertical furnace, separated from the air stream in a baghouse, passed through a rotary valve that maintains the air seal, screened for particle size, and routed by a diverter either to waste or to the production process.

Furnace behavior varied with ore type, ambient conditions, equipment condition, and previous run state. Startup required careful control of feed, gas, temperature, and material routing before stable product could be sent downstream.

Startup waste

Usable expanded perlite was routed to waste during startup until the furnace reached stable operation.

Bulk density variability

Bulk density depended on furnace temperature, feed behavior, ore properties, airflow, gas flow, and delayed manual sampling.

Control instability and operator burden

Multiple interacting loops made the furnace sensitive to tuning, deadbands, noisy signals, and operator setup.

Engineering approach

The work focused on three connected changes: controlled startup states, live density feedback, and more stable furnace tuning. Each change was developed around the same practical goal: make the system more repeatable without making it harder for operators to run.

Zero waste startup sequence

I developed a startup sequence that transitioned the furnace from purge and ignition into controlled feeding while capturing usable expanded perlite. The sequence used previous operating conditions to initialize feed and gas behavior, then used ratio-based ramping logic to coordinate the gas ramp, feed ramp, material handling startup, diverter transition, and load control activation.

  1. Purge and ignition
  2. Baghouse rotary valve and screener startup
  3. Initial waste routing during unstable conditions
  4. Diverter transition from waste to process
  5. Gas ramp, feed ramp, and load control activation

The main engineering challenge was building, testing, and tuning the ratio-based ramping logic so feed and gas changes stayed coordinated as the furnace moved into a stable production state.

Live bulk density feedback control

I implemented a live bulk density control loop using weigh feeder data. The system calculated bulk density from scale load and material cross sectional area, filtered the signal using a rolling average, and used the result to adjust the furnace stack temperature set point.

The major shift was moving from delayed manual correction toward live process feedback. Instead of waiting for manual samples to reveal density drift, the furnace could use weigh feeder data to make controlled set point adjustments.

Furnace stability, load control, and DOE tuning

Control loop stability

The furnace had multiple interacting control loops, including stack temperature, chamber temperature, mixer pressure, airflow, and gas flow. I tuned the system to reduce oscillation and improve process stability.

The improved control strategy favored load control, using ore feed as the primary manipulated variable while keeping air and fuel more stable. This reduced unnecessary interaction between gas and airflow loops and improved repeatability.

DOE parameter development

I used DOE methods to screen furnace variables, identify interactions, and refine run parameters by ore type. The workflow included initial variable screening, repeated high resolution trials, control improvements to reduce outside variation, rescreening, Minitab and Excel analysis, parameter implementation, and iteration.

  1. Gas rate
  2. Chamber temperature
  3. Mixer pressure
  4. Ore type
  5. Bulk density
  6. Air to fuel ratio

Production validation

I validated changes on one production furnace first, reviewed process behavior during live operation, and then replicated proven logic and settings across the broader furnace system. Automatic control was gated by communication status, valid density range, stack temperature, furnace state, and time-in-state checks.

  • Single-furnace production trials before broader rollout
  • Bulk density trend review
  • Scale communication, density range, and operating-state checks
  • Stack temperature and time-in-state permissives
  • Replication of validated changes to additional furnaces

Operator interface and standard work

A major part of the project was making the system usable by production teams. I documented basic condition checks, updated operating standards, and helped define the sampling, calibration, and training workflow needed to support automatic bulk density control.

  • HMI updates to distinguish manual and automatic control states
  • Clearer visibility for set points and process values
  • Sampling workflow updates for bulk density verification
  • Scale calibration and tracking requirements
  • Basic condition checks and training requirements
